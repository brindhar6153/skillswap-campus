# Phase 16D — Google Play Console App Creation Information

This document contains the exact administrative details to enter when creating the **SkillSwap Campus** application in the [Google Play Console](https://play.google.com/console).

---

## 1. Application Creation Details

| Field in Play Console | Value to Enter | Notes |
| :--- | :--- | :--- |
| **App name** | `SkillSwap Campus` | Display name on Google Play (16 / 30 chars). |
| **Default language** | `English (United States) - en-US` | Default listing locale. |
| **App or game** | **App** | Utility / Educational software. |
| **Free or paid** | **Free** | SkillSwap Campus operates on a non-monetary time-bank credit model with no upfront download fee. |
| **Package name / Application ID** | `com.example.skillswapcampus` | Fixed unique package identifier compiled in the AAB. |

---

## 2. Category & Tag Recommendations

* **Primary Category**: **Education**
  * *Rationale*: SkillSwap Campus is designed specifically for academic peer-to-peer tutoring, course assistance, and student skill learning.
* **Secondary Category / Tags**:
  1. `Education`
  2. `Productivity`
  3. `Communication`
  4. `Social`
  5. `Learning`

## 3. Required Legal & Policy Declarations

Check the mandatory compliance boxes:
* ☑ **Developer Program Policies**: Acknowledge that the application and developer abide by Google Play Developer Program Policies.
* ☑ **US Export Laws**: Confirm compliance with United States export regulations.
