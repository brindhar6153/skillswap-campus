# Phase 16C — Final Google Play Submission Checklist: SkillSwap Campus

Use this master checklist before submitting **SkillSwap Campus** for review in the [Google Play Console](https://play.google.com/console).

---

## 1. Submission Readiness Checklist

- [ ] **Google Play developer account ready**: \$25 USD registration fee paid and identity verification completed.
- [ ] **Account holder meets Google requirements**: Developer is 18 years of age or older with active payment profile.
- [ ] **App created in Play Console**: New app created with Title `SkillSwap Campus`, Type `App`, Status `Free`.
- [ ] **App name entered**: App name set to `SkillSwap Campus` (16 / 30 characters).
- [ ] **App category selected**: Primary category set to `Education`, secondary tags added.
- [ ] **Contact email entered**: Public developer/support contact email provided.
- [ ] **Privacy policy URL ready**: Public HTTPS link hosting the policy from `docs/privacy_policy_draft.md` entered.
- [ ] **Data Safety completed**: Questionnaire submitted using the verified answers in `docs/google_play_data_safety.md`.
- [ ] **Content rating completed**: IARC questionnaire submitted using `docs/google_play_content_rating.md`.
- [ ] **Target audience completed**: Target age set (e.g. `18 and over` or account holder determined group, appeal to children: No).
- [ ] **App access information prepared**: Reviewer instructions provided under **App access** using `docs/play_review_access.md`.
- [ ] **Store description ready**: Text from `docs/google_play_store_listing_final.md` copied into Short (78 chars) and Full descriptions.
- [ ] **App icon ready**: `dist/play_store_assets/app_icon_512x512.png` uploaded (512x512 px).
- [ ] **Feature graphic ready**: `dist/play_store_assets/feature_graphic_1024x500.png` uploaded (1024x500 px).
- [ ] **Screenshots ready**: All 6 PNG screenshots from `dist/play_store_assets/` uploaded in numerical order.
- [ ] **Testing requirements completed if applicable**: Internal test verified and closed testing completed if required by account status (`DEPENDS ON GOOGLE PLAY ACCOUNT STATUS`).
- [ ] **Final AAB uploaded**: `dist/SkillSwapCampus-final.aab` uploaded to the release track.
- [ ] **Release warnings reviewed**: Pre-launch report reviewed with 0 blocking errors.
- [ ] **Policy warnings reviewed**: Declarations confirmed (No ads, no sensitive background permissions).
- [ ] **Final submission reviewed**: Release review summary checked for accuracy.
- [ ] **Ready for Google review**: Click **Start rollout to Production** (or **Submit for review**).
