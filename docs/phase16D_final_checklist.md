# Phase 16D — Master Google Play Submission Checklist: SkillSwap Campus

This checklist must be used by the authorized developer account holder when publishing **SkillSwap Campus** via the [Google Play Console](https://play.google.com/console).

---

## 1. Master Checklist

- [ ] **Google Play developer account ready**: Account active, identity verified, registration fee paid.
- [ ] **Account holder meets Google's requirements**: 18+ years of age, valid payment profile.
- [ ] **SkillSwap Campus app created**: Created under **All apps → Create app** (Name: `SkillSwap Campus`, Type: `App`, Free).
- [ ] **Package name confirmed**: `com.example.skillswapcampus` matches the generated AAB.
- [ ] **Store listing completed**: Short and Full descriptions from `docs/phase16D_store_listing.md` entered.
- [ ] **App icon uploaded**: `dist/play_store_assets/app_icon_512x512.png` uploaded (512x512).
- [ ] **Screenshots uploaded**: 6 phone screenshots from `dist/play_store_assets/` uploaded in order.
- [ ] **Feature graphic uploaded if required**: `dist/play_store_assets/feature_graphic_1024x500.png` uploaded (1024x500).
- [ ] **Privacy policy publicly hosted**: `docs/privacy_policy_draft.md` hosted at a public HTTPS URL.
- [ ] **Privacy policy URL entered**: Entered into **App content → Privacy policy**.
- [ ] **Data Safety completed**: Questionnaire completed using `docs/phase16D_data_safety_verification.md`.
- [ ] **Content Rating completed**: IARC questionnaire completed using `docs/google_play_content_rating.md`.
- [ ] **Target Audience completed**: Target age set (Recommended `18 and over` or account holder selection).
- [ ] **App Access completed**: Demo reviewer credentials entered from `docs/phase16D_reviewer_access.md`.
- [ ] **Testing requirement checked**: Checked whether Closed Testing (20 testers for 14 days) is mandated (`DEPENDS ON GOOGLE PLAY ACCOUNT STATUS`).
- [ ] **Testing completed if required**: Completed 14-day closed test if applicable to account status.
- [ ] **Final AAB uploaded**: `dist/SkillSwapCampus-final.aab` uploaded to release track.
- [ ] **Release warnings resolved**: Pre-launch report reviewed with 0 blocking errors.
- [ ] **Policy warnings resolved**: Declarations verified (No ads, no sensitive hardware permissions).
- [ ] **Ready for submission**: Click **Review release → Start rollout to Production** (or **Submit for review**).
